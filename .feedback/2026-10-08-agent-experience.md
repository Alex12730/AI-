# 本次实现反馈记录

## 已遇到的摩擦点

- 项目初始目录为空且尚未初始化 Git，需要先建立规格、计划和基础工程。
- 系统 PATH 没有 Python，但 Codex 工作区依赖提供了 Python 3.12；后续使用固定绝对路径，避免误报“缺少 Python”。
- Impeccable 前端上下文引擎未安装，默认缓存目录不可写且首次安装需要网络，因此无法运行随机概念生成器。本次依据用户已确认的产品流程建立保守的 Operate 界面，并在最终验收中单独检查可用性。
- 当前没有模型权重和 A6000 基准环境；软件接入与准入门槛可以实现，真实性能数据必须留给目标工作站实测，不能伪造。
- 新仓库首次提交因缺少 Git 作者身份失败。处理方式是仅为本仓库设置 `Codex <codex@local.invalid>`，不污染用户全局配置。
- Superpowers 的 `sdd-workspace` 脚本在本机 Git Bash 中找不到 `basename`，脚本没有建立台账。已按脚本公开的目录和首行格式手工建立等价台账。

## 改进建议

- 为项目固定一个受控 Python 虚拟环境，并把启动脚本绑定到该解释器。
- 模型安装与平台代码分开验收：先用 Demo 适配器验证状态机，再逐个启用真实 Profile。
- 前端设计工具若要使用，应把引擎缓存配置到可写工作区或预先安装，避免实现中途联网。
