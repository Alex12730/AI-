# 视频工作台局域网访问设计

## 目的

让连接同一路由器或 Wi-Fi 的电脑通过浏览器使用视频工作台。模型推理、ComfyUI、任务队列、温度监控和文件存储仍只在主机运行，其他电脑不安装模型，也不直接访问 ComfyUI。

## 范围

- 日常启动入口启用局域网监听，并继续在主机自动打开 `http://127.0.0.1:8000/create`。
- 启动后显示主机可用的局域网访问地址，例如 `http://192.168.1.25:8000`。
- Windows 防火墙规则只允许“专用网络”中的本地子网访问 TCP 8000。
- 工作台仍要求登录；首次账号初始化 `/setup` 仍只允许主机回环地址访问。
- ComfyUI 继续只使用 `127.0.0.1:8188`，不得向局域网或公网开放。

## 不在本次范围

- 不开放公网端口，不配置路由器端口转发。
- 不提供互联网远程访问；以后如需要，应通过 Tailscale、WireGuard 等专网单独设计。
- 本次不增加多账号权限层级，也不改变现有任务调度和模型选择。
- 本次不部署 HTTPS；适用边界为可信的家庭或办公专用局域网。

## 方案比较与选择

1. **直接开放局域网 8000（选定）**：改动少、操作简单，符合“同一路由器或 Wi-Fi”场景。通过 Windows 防火墙把范围限制为专用网络和本地子网。
2. **局域网 HTTPS 反向代理**：能加密浏览器通信，但需要证书、代理服务和额外运维，不适合作为当前第一阶段。
3. **虚拟专网**：适合异地互联网访问；当前没有异地访问需求，不增加这一层。

## 启动和关闭行为

- 仓库通用启动脚本保留安全默认值 `127.0.0.1`，增加显式的监听地址参数。
- 本机交付目录中的日常启动器显式传入局域网监听值 `0.0.0.0`。
- 局域网防火墙配置使用独立、可重复执行的脚本；脚本只管理自己命名的规则，并提供关闭局域网访问的对应操作。
- 如果防火墙规则未建立或当前网络不是“专用网络”，主机仍可使用，启动信息明确提示局域网访问尚不可用。
- 工作台进程、Worker 和 ComfyUI 的所有权检查及安全重启行为保持不变。

## 安全边界

- 仅开放工作台 TCP 8000；8188、数据库、模型目录和文件共享端口均不开放。
- 防火墙规则限定 `Profile=Private`、`RemoteAddress=LocalSubnet`，不得使用 `Any` 公网范围。
- 匿名访问继续跳转登录；账号密码和会话密钥不得写进启动脚本或 Git。
- 账号初始化继续只能在主机执行，避免局域网中的设备抢先创建账号。
- 上传和生成文件继续经过现有权限检查、大小限制、路径隔离和 CSRF 校验。

## 用户操作

1. 主机首次启用局域网访问时，以管理员权限运行一次防火墙配置脚本，并确认当前 Wi-Fi/以太网为“专用网络”。
2. 双击现有“启动视频自动化工作站”入口。
3. 启动窗口显示本机入口和局域网入口。
4. 其他电脑在浏览器打开局域网入口并使用现有工作账号登录。
5. 主机保持开机，后台、Worker、ComfyUI 和温度监控保持运行；其他电脑关闭浏览器不会中断任务。

## 验收条件

- 主机仍可通过 `127.0.0.1:8000` 登录和制作。
- 同一专用局域网中的另一台电脑可以打开局域网地址、登录、查看队列并提交一个测试任务。
- 非登录用户不能查看作品或提交任务。
- `/setup` 从其他电脑访问仍返回拒绝。
- `8188` 从其他电脑无法访问。
- Windows 防火墙规则只覆盖专用网络、本地子网和 TCP 8000。
- 关闭局域网访问后，主机仍可正常使用，其他电脑无法再连接。
