# 个人全离线视频工作台设计补充

日期：2026-10-22。版本：1.1。状态：已纳入补充评审意见的完整设计稿，新增功能尚未实施。代码依据：部署接入提交 `460697d`，基础设计提交 `52c92c7`。第 15 至 24 节补齐实现合同、验收证据和运维要求；同一事项以这些细则为准。

本文件补充既有工作站设计。与旧文档冲突时，本次用户确认后的个人使用流程、Windows 本机部署和零公网依赖要求优先。没有冲突的队列、权限、模型准入、媒体质检和追溯设计继续保留。

## 1. 用户目标与完成标准

用户是视频模型新手，需要兼顾产品教程、知识讲解、口播、故事短片和创意广告。日常制作不使用 Codex，不操作 ComfyUI 节点，不写命令，不手填模型参数，不购买云端生成服务。

目标体验：双击桌面“视频工作台” → 说明想做的视频、放入素材 → 确认分镜 → 自动安排模型、生成和合成 → 看成片并保存。单人使用只保留两个人工检查点：开始制作前确认内容，完成后决定是否导出或重做某个镜头。

成功必须同时满足：

- 关闭 Codex、拔网线/关闭 Wi-Fi 后，重启电脑，仍能从桌面入口完成一条视频。
- 应用代码、Python、ComfyUI、模型、字体、模板和帮助都在本地；不引用 Codex 缓存目录和开发工具的 Python。
- 生成期间没有公网 DNS、HTTP、HTTPS、遥测、检查更新、素材搜索或缺文件自动下载。不得失败后转云端。
- 只在“已安装、输入能力匹配、当前配置通过本机生产验收”的模型中自动选择。
- 一次提交自动完成后续依赖任务，关闭界面后任务继续，重开能看到进度；重启后保留已完成镜头。
- 所有自动推荐可解释；用户可以只改一个镜头，无须重做整片。

约定：“不使用流量”在本项目中指不使用互联网流量。`127.0.0.1` 是电脑内部通信，允许保留。要让整台电脑的其他软件也不产生任何公网流量，最可靠的使用方式是物理断网；本工作台不能替其他应用作零流量承诺。

## 3. 采用的方案

| 方案 | 优点 | 代价与结论 |
| --- | --- | --- |
| A. 保留本地网页，补专用运行环境、桌面启动器和制作向导 | 最大限度复用已有代码，日常无命令；断网可用 | 推荐作为第一阶段交付 |
| B. 再封装独立窗口和固定版本 WebView 运行时 | 更像独立软件，便于限定宿主外联 | 作为后续封装，不能先花时间重写视频业务 |
| C. 直接以 ComfyUI 节点界面为日常入口 | 可调参数多 | 学习成本高，不符合用户目标；仅供维护使用 |

不新建另一套视频生产平台，不同时引入云服务、远程账户、插件市场和复杂时间线编辑器。保留现有 FastAPI、SQLite、Jinja2、Worker、FFmpeg 和 ComfyUI。

## 4. 首页与四步制作流程

默认导航只有“开始制作”“我的作品”“素材库”；“帮助与设置”放到底部。运行监控、模型参数、账号管理和维护入口放入设置。首页主按钮只有“开始制作”，下方提供“继续上次制作”。

保持现有暖白底、深色文字、清楚的状态和系统中文字体。调整的是操作结构，不用重新学习一套花哨的界面。

### 第一步：告诉工作台想做什么

主问题为“你想做一个什么视频？”，带三个可直接填写的示例。类型可自动判断，也可点选：产品与教程、知识与口播、故事与创意。

默认只显示：

1. 需求描述或现成文案。
2. 时长：30 秒、60 秒、自己填写；这是整片目标，不是要求模型一次生成这么长。
3. 画面方向：横屏“电脑/课程”，竖屏“手机短视频”。

点击“加入素材”可拖入视频、图片、音频和本地字幕。“声音”默认选择“保留素材声音/暂不加配音”；系统根据已安装能力提供“我自己录”“导入声音”“本地配音”。未准备好的选项说明原因，不让用户开始后才遇到失败。

### 第二步：确认系统安排的镜头

分镜以顺序列表显示：画面要做什么、说什么、来自哪里、预计占几秒。用户通常只改文案或替换素材。

例：“第 2 段：展示真实软件操作；用你导入的录屏，不需要生成。”或“第 4 段：生成办公室氛围画面；自动选择 Wan，原因：这一段不需要同步对白。”

高级信息折叠后才显示模型名、种子、负面提示词和已验收参数。人物是否需要逐字念稿、产品是否必须保持原样，是醒目的内容约束，不作为技术参数隐藏。

主按钮“确认并开始制作”。个人模式将旧有“提交审批→批准分镜”合并为这个动作；服务端仍以当前用户身份记录批准、版本快照和审计，不删除权限校验。团队模式保留原来的审批流程。

### 第三步：自动制作

显示“正在制作第 2/6 段”“正在配音”“正在合成”，而非只显示一个总百分比。镜头按项目顺序呈现，完成的可以先看。无可靠估计时显示阶段，不编造剩余分钟数。

默认开始后自动跑到可预览成片。可选“每段生成后让我先看”，该选项默认关闭。

“暂停后续制作”表示当前镜头完成后暂停；不承诺暂停任意扩散采样步骤并无损续算。“停止当前生成”使用任务 ID 定向取消，说明当前镜头需从头重做；已经完成的镜头保留。

### 第四步：预览和保存

成片播放器为主，按钮为“保存视频”“只改这一段”“复制项目”。保存旁提供“打开文件夹”；高级下载再提供分镜素材、字幕和制作记录。

返工只有三个常用动作：“换一版画面”“修改描述”“换成我的素材”。生成新版本后由用户选择替换，不自动覆盖满意版本。

默认导出横屏 1920×1080 或竖屏 1080×1920、24fps、H.264/AAC。导出尺寸不代表模型原生生成了 1080p，也不代表提高了真实细节。超分作为另行验收的高级选项，默认关闭。

## 5. 必须内置的六条制作流程

| 流程 | 用户提供 | 系统安排 | 缺少条件时 |
| --- | --- | --- | --- |
| 产品介绍/软件教程 | 卖点、真实截图/录屏、可选配音 | 真实演示为主体，标题和字幕由本地合成，少量生成氛围镜头 | 真实界面缺失则要求补素材或改成纯文字介绍，不生成假界面 |
| 知识讲解 | 讲稿、可选录音/图片 | 分段解释，搭配素材/图文/空镜，字幕与音频对齐 | 无本地配音时提供录音或导入，不启用云配音 |
| 真人口播剪辑 | 用户自己拍的口播 | 整理片段、加字幕和插画面 | 第一阶段不承诺自动去所有口误；保留原片和确认点 |
| AI 人物表演/氛围短片 | 场景、人物动作与声音偏好 | H3/LTX 候选生成短段，用户确认声音和画面 | 不保证指定台词逐字正确 |
| 故事短片 | 故事、角色说明、可选参考图 | 按场景拆短镜头，冻结人物设定，再组合成片 | 参考图流程未接通时明确限制；不保证仅靠同一种子保持同一张脸 |
| 创意广告 | 产品真实素材、卖点、文案 | 真实产品特写与生成环境镜头组合，末尾加清晰字幕/行动文案 | 商标、价格、包装文字使用真实图层，不交给视频模型绘字 |

附加“从已有视频开始”：即使生成模型临时不可用，用户仍可在本地导入、整理、加字幕并合成。模板包含分镜结构、素材检查、声音策略和导出默认值，不能只有几段提示词。

## 6. 自动选模型的明确规则

以下是针对当前已接入版本的初始路由政策，不是三模型画质排名。最终偏好需要用本机、同题材、同交付条件的对比样片校准。

| 画面或约束 | 默认处理 | 自动匹配理由 |
| --- | --- | --- |
| 软件按钮、操作步骤、准确文字、产品外观 | 用户真实视频/图片 + FFmpeg 图层 | 需要准确和可验证，不应生成替代事实 |
| 风景、环境、运动、转场空镜，不需要原生声音 | Wan 2.2 优先 | 当前已接通画面生成，声音另行处理 |
| 需要环境声或人物表演的短镜头 | MiniMax H3 优先，LTX 为候选 | 当前 H3/LTX 接入均能输出音视频，按匹配档位和对比反馈选择 |
| 希望比较另一种音视频表达，或已验收的较长单镜头 | LTX-2.3 候选 | 只有本机相应时长已验收才可用，不能因为“支持 20 秒”就默认选它 |
| 必须逐字说出一段话，但不要求人物对口型 | 录音/导入音频，或已安装的离线配音 + 画面 | 把台词准确度与画面生成解耦 |
| 必须出现说话人物且口型对齐 | 真人录制，或已验收的独立口型流程 | 当前三模型原生音频不作为精确口型保证 |
| 跨镜头同一角色 | 已验收参考图流程 + 角色素材约束 + 人工连续性检查 | 不把“同一种子”当作身份锁定技术 |

决策顺序固定为：用户硬约束 → 素材优先 → 功能门禁 → 当前配置准入 → 题材偏好 → 本机历史耗时与失败记录。LTX、H3 不因原生有声音就被判断为“任何视频都比 Wan 好”。

系统返回推荐方案、理由和可用备选。没有候选时应提出“改成两个已验收短镜头”“换真实素材”等具体办法，得到用户确认再变更；不能自动降画质、换台词、换方向或转云端。

自动选模型的单位是镜头。60 秒广告可以混用真实素材、Wan、H3 和 LTX，不要求整片只选一个模型。默认生成单位先收敛到已验收的 5 秒镜头，再逐步开放 10/15/20 秒。

## 7. 声音、字幕、文案的边界

三种视频模型不能覆盖完整视频生产链。

- 已有视频编码器不直接充当聊天/写稿服务。第一阶段采用可编辑内置脚本模板和确定性分镜规则；自由描述的本地编导作为独立能力包，接入现有 `qwen-local` 配置，另行固定模型、运行时与权重版本并验收。缺包时必须明确处于模板模式。
- 精确讲稿优先支持用户自己的录音和导入音频，避免基础流程额外依赖大模型。后续接通现有 `cosyvoice-3` 配置后才显示“本地配音”；每句合成、试听后以实际音频时长规划镜头。
- 自动字幕需要独立本地转写/对齐能力包。未安装时提供导入 SRT 或逐句文案+人工校时，不把按字数估算的时间轴标成“准确识别”。
- `musetalk-1.5` 作为可选精确口型包；先完成图像、人脸、音频、对齐和输出验收，再启用数字人口播模板。
- 原生环境音与讲解音轨分开管理。出现精确旁白时可降低或移除原声，但若画面中有明显说话口型，不能宣称换音轨后口型仍同步。
- 背景音乐只能来自用户本地文件或打包且允许使用的素材。默认不加音乐，不提供在线搜歌入口。

能力包都是“首次部署时准备或从 U 盘导入”，日常制作绝不触发下载。用户不需要管理其模型名，设置页用“帮我写稿”“自动配音”“识别字幕”“人物对口型”表达用途。

## 8. 首次准备与生产验收

设置向导统一显示三种状态：“文件已准备”“试片已成功”“正式制作已验证”。不得用一个绿色“已安装”掩盖后两项。

首次向导依次完成：选择数据盘、检查专用运行环境、核对模型文件、准备基础素材/字体、生成小样、运行所选正式档位、试听检查、断网验收。耗时任务可以退出界面后继续，结果保存在本地，不在每次新建视频时重复测试。

第一批正式档位建议为三个模型 × 5 秒 × 横/竖两个方向；每组合沿用十次规则，共 60 次，不承诺很快完成。可先验收实际急需的一个组合，其余后台分批进行。需要用户确认一次测试范围后才开始，不因打开首页自动占满 GPU。

继续遵守每档 10 次、至少 9 次成功、无 OOM、无损坏文件。成功样本保留实际耗时、显存、内存、温度和音画检查记录。自动采样客观指标，声音/画面一致性仍需要真实人工评价；不得为满足数据库字段伪填同步分数或画质分数。

对比画质时提供同一题材样片并由用户选择偏好；这种偏好只用于适配已通过技术验收的模型。样片通过不代表任意提示词都成功。

配置指纹扩展到模型文件校验值、工作流、桥接器、引擎版本和关键依赖。版本改变后原档位显示“需要重新验证”。不能仅更改模型文件却沿用旧十次记录。

## 9. 全离线与独立启动

### 部署闭包

代码目录、运行目录、模型目录、用户项目目录分开；路径来自部署清单，允许安装在当前 E 盘并通过启动器定位。现有权重复用，不重复复制百 GB 文件。

```text
安装目录/
  app/                         工作台代码、模板和本地帮助
  runtime/workstation-python/   专用业务 Python，不依赖 Codex
  runtime/ComfyUI/              已锁定的生成引擎与专用 Python
  runtime/ffmpeg/               视频处理工具
  models/                      共享的本地权重
  resources/                   字体、模板、示例、离线帮助
  deployment.json              位置、版本、校验值和能力清单
用户数据目录/
  projects/ assets/ archive/ logs/ workstation.db
```

离线包需包含全部 Python 依赖、节点依赖、音频处理器、分词器、模型配置和字体。将当前宽范围依赖单独锁定为经过验收的安装版本；源码开发依赖不等于离线安装包。

缺少文件时明确说“缺少本地配音文件，请在设置中导入离线包”，立即停止该功能，不能自动访问 Hugging Face、ModelScope、GitHub 或 pip。所有路径应可在设置中“检查/重新定位”。

### 运行期约束

- 业务 Web 只监听 `127.0.0.1:8000`，ComfyUI 只监听 `127.0.0.1:8188`；本次默认关闭局域网使用。
- 模型加载使用本地路径和支持的离线选项；启动前核验资源闭包。相关库可设置 `HF_HUB_OFFLINE`、`TRANSFORMERS_OFFLINE` 等，但环境变量不能替代实际断网测试和系统约束。
- 禁止在线字体、CDN 脚本、统计上报、自动检查更新、自动安装节点；只允许打包好的已审核节点。
- 应用自己的 URL 策略只放行回环，禁代理和重定向，前端 CSP 限制资源为本地同源。
- 对专用运行进程配置可逆的公网出站限制，保留本机回环；实际规则必须验证。当前业务 Python 的基础进程属于 Codex 缓存，迁移前不能直接给这个共享 Python 加全局阻断规则。
- 普通浏览器自身可能存在独立后台联网行为，不能算作工作台已控制的进程。整机零流量使用断网；若要求电脑同时联网办公而该窗口也严格不外联，后续使用专用受限窗口宿主，不能阻断用户日常浏览器。
- 离线模式里隐藏 GitHub 登录、更新和上传入口。维护更新使用完整离线包，验证后手动切换版本，可回退。

### 桌面入口

提供真正可双击的 Windows 快捷方式，后台启动器执行环境检查、单实例判断、启动本机服务、等待就绪、打开本地操作页。用户不用右键运行 PowerShell，不看到终端。

任务进程独立于 Codex和网页窗口。关闭窗口时提醒“任务继续/完成当前段后暂停”，不默认杀掉 GPU 任务。关机前持久化状态；下次只重做未完成的当前镜头，不承诺恢复采样器中间显存状态。

统一现有两个启动路径使用的会话密钥位置，避免手动启动与计划任务互相使登录失效。默认不自动登记开机任务；首次设置可选“登录 Windows 后自动准备”，包含引擎、Web、Worker 的一致启动顺序。

## 10. 整片编排和错误恢复

在现有单 GPU Worker 上增加“制作计划”，不是另起第二套并行队列。

制作计划依次包含：素材校验 → 分镜冻结 → 音频准备 → 按镜头渲染/导入 → 媒体检查 → 当前版本选择 → 字幕时间轴 → 合成 → 成片质检 → 本地导出。

每节点记录输入版本、执行参数、所依赖资产、结果和失败原因。只有依赖成功才入队，重复点击“继续”不得重复出片。合成只引用计划快照中的明确资产 ID，不能简单挑目录中最新文件。

重做镜头时标记依赖它的合成为过期，已完成的其他镜头继续复用。自动完成技术步骤后默认选择通过质检的新结果；用户手动选定的版本不能被后台新任务覆盖。

所有使用 GPU 的视频、未来文案、配音、识别和口型任务都遵守统一资源调度。必要时卸载上一个模型以留出余量，不同时启动三个大模型抢显存。检测到维护人员直接在 ComfyUI 中运行其他任务时等待或说明引擎占用，不抢占或中断别人任务。

错误用普通中文说明：

| 原因 | 用户看到 | 操作 |
| --- | --- | --- |
| 未验收 | 这个制作规格还没验证 | 打开准备向导，或确认改用已验证短镜头 |
| 缺真实素材 | 这一段需要真实操作画面 | 加入录屏或改成图文说明 |
| 显存不足 | 当前设置超出显卡能力 | 保留已完成结果，确认拆短或选已验证方案 |
| 磁盘不足 | 保存空间不足 | 显示所在磁盘和清理预览，不自动删原素材 |
| 模型文件缺失 | 所需文件不在本机 | 重新定位目录或导入离线包 |
| 指定台词不适配 | 这个人物镜头不能保证逐字说稿 | 选真人录制、画外音或已准备的口型流程 |

基础设施错误保留现有有限重试；OOM、画质问题和用户取消不无限重试。运行中取消必须从项目→队列→Worker→本次 ComfyUI prompt_id 全链路生效，不能只改界面文字。

## 12. 交付顺序

### 第一阶段：独立离线、三类题材均可完成的基础制作

交付专用运行环境和桌面启动；模板化需求输入、真实素材优先、自动路由、整片串行生成、录音/导入声音、字幕导入/编辑、自动合成和预览导出。保留模板模式的边界，不把它宣传成已经有自由写稿模型。

先让“录屏教程”“配自己声音的知识视频”“由短生成镜头构成的创意片”分别跑通。三类入口都存在；未准备的精确口型等选项明确不可用，而不是暗中调用替代服务。

### 第二阶段：减少准备工作

接通本地文案、配音、字幕转写/对齐能力包，导入和设置都通过工作台完成；加口型包前先验证它与用户素材的适配。经批准可增加固定运行时的独立窗口。

### 第三阶段：角色与画面控制

接通参考图片和首尾帧、角色素材卡、跨镜头检查，再扩展较长档位和可选超分。长片仍通过分镜拼接，不能用单个视频模型“任意连续生成”替代。

不在设计阶段承诺各阶段天数或每分钟出片速度。根据第一轮本机正式档位记录再估计，尤其不能用加载缓存后的小样耗时推算整片耗时。

## 13. 必须通过的验收场景

1. 全部资源准备完成后断网、关闭 Codex、重启，从桌面打开并完成新项目；同时观察应用进程的外联记录，不能仅凭页面上的“离线”标识通过。
2. 检查所有运行进程路径，不引用 `.codex`、开发技能目录或系统临时安装器。
3. 需求“教程中的按钮名称必须准确”时只路由到真实素材/本地文字图层。
4. 同一项目包含录屏、空镜、音视频表演时分别匹配，已验收约束逐镜头生效。
5. 三模型只有 configured、没有准入记录时，不产生生产任务；Demo 不计为真实生成成功。
6. 请求不存在的 20 秒 H3 时，提出拆镜或其他已验收方案，用户确认前不改需求。
7. 请求逐字讲稿时，不以 H3/LTX 的自由原生对白冒充精确配音。
8. 中文目录、含空格文件名、中文提示词，以及以 `--` 开头的文字都能正确处理。
9. 制作到中途关闭网页，重开能看到进度；重启电脑后复用已完成且通过校验的镜头。
10. 运行中停止只影响本项目自己的任务；任务未真正终止时不能显示“已停止”。
11. 第三个镜头返工只使它与后续合成失效，前两个镜头和原满意版本保留。
12. 缺字幕/配音包时清楚提示并保留录音、导入或人工校时路径，全程无下载请求。
13. 合成检查编码、音轨、时长、黑帧/异常静帧；画质、事实准确和音画观感仍由人预览，自动质检不能替代内容验收。
14. 用户不接触模型页、不打开 Codex、不操作命令，能按内置帮助完成三类示例作品。

## 14. 用户需要审阅的决定

确认本稿时主要确认：采用统一四步向导；个人模式合并自我审批；第一阶段先用录音/导入和模板做全离线闭环；高级能力按本地包准备度逐项启用；正式模型仍先完成一次性本机档位验收。

确认设计稿后再写逐任务实施计划，并选择执行方式。本稿尚不表示这些新按钮与流程已经出现在现有网页中。

## 15. 功能状态与版本管理

“文件已准备”“执行已接通”“生产已验证”“用户入口已上线”是四个独立维度，不合并成一个绿灯。模型文件存在不代表某个输入模式或时长已经可用；入口上线也可以因生产验收未完成而禁用。所有状态显示检查时间和具体原因。

| 功能 | 当前证据 | 用户可用范围 | 目标门槛 |
| --- | --- | --- | --- |
| 三模型文生视频 | 权重与本地调用已接通，有历史小样；正式档位记录为 0 | 模型管理可见，正式生成须受准入限制 | 对应模型、配置、时长和方向验收通过 |
| 真实视频导入与本地合成 | 已有导入、质检、预览、合成实现 | 按现有审批流程操作 | 新向导对其进行简化，不重复实现编码器 |
| 自动选择模型与整片编排 | 本稿设计，尚未上线 | 当前仍需逐镜头操作 | 路由、计划依赖和新手验收均通过 |
| 图片与首尾帧生成 | 当前图与 Worker 未完整接通 | 不显示为已可生产 | 输入传递、参考约束和输出分别验收 |
| 写稿 配音 自动字幕 口型 | 部分仅有配置登记，不能据此确认包已安装 | 不标记为可用 | 包文件、适配器、输入输出和质量全部验证 |
| 脱离 Codex 的专用环境 | 当前业务基础 Python 仍引用其缓存 | 现有脚本可启动不等于专用环境已完成 | 冷启动进程路径检查与断网新项目通过 |

版本记录由系统产生，包括应用提交、数据库版本、引擎版本、依赖锁文件、模型与工作流指纹。首次准备页、模型页和制作页必须读取同一状态来源。用户手工改目录或替换权重后，先重新校验，不能继续显示旧的“生产已验证”。

能力状态的目标字段为 feature_id、files_ready、adapter_ready、validated_presets、ui_available、unavailable_reason、checked_at、evidence_id。缺文件、未接通、未验收、入口未上线分别说明，不用“发生未知错误”代替。

## 16. 安装启动与离线资源合同

### 部署清单

`deployment.json` 的格式版本固定为 1。它是位置与依赖清单，不是可以任意执行脚本的安装器。导入时校验格式版本，未知必需字段或不支持的版本直接拒绝并保留旧配置。

| 字段组 | 必须包含 | 校验要求 |
| --- | --- | --- |
| release | release_id、app_commit、schema_version、创建时间 | 与所导入完整包一致，不从文件名推测版本 |
| runtimes | 业务 Python、ComfyUI Python、FFmpeg 的相对路径和版本 | 规范化后位于安装目录内，不引用 Codex 或技能目录 |
| services | Web 与引擎的回环地址、服务角色 | 默认仅 127.0.0.1 的 8000 与 8188，不接受公网端点 |
| assets | asset_id、相对路径、字节大小、SHA256、用途、必需性 | 实际文件逐一核对；拒绝越界路径和逃逸链接 |
| packages | package_id、版本、所需资源 ID、依赖、适配器版本 | 依赖闭合；模板包不能携带任意执行命令 |
| licenses | 模型、字体、音乐及示例素材的说明文件位置 | 与离线包一起保留；缺少必需说明时不发布该包 |

来源网址可作为维护记录保留，但制作程序不得访问。SHA256 证明文件完整性，不单独证明发布者可信；包必须来自用户认可的发布来源，来源不能确认时不自动执行其中程序。

### 导入和路径迁移

设置页选择本地目录或离线包 → 显示版本、空间和影响范围 → 解到临时区 → 检查清单、依赖和校验值 → 验证完成后切换生效。压缩文件只提取清单内的普通文件，拒绝路径穿越，提取总量不得超过清单声明。失败只清理此次临时区，不改旧目录。

安装目录可移动，用户数据目录独立保存。先更改新位置并验证，再更新部署清单和快捷方式。模型采用重新定位已有文件，避免再次复制。已有项目资产缺失时显示原路径和重新定位按钮，不以同名文件自动替换。

### 启动与单实例

启动器检查专用 Python → 读取清单与数据位置 → 获得本机工作台实例锁 → 检查引擎 → 启动 Web → 确认数据库就绪 → 启动 Worker → 打开页面。默认等待上限 120 秒；超时提供“重试”“查看本地诊断”，不能反复启动新实例。

再次双击只打开已有工作台。端口被其他程序占用时显示占用程序与端口，不杀进程、不自动暴露到其他地址。判断服务归属要结合进程路径和本次部署标识，不能仅凭任意服务返回 HTTP 200。

统一会话密钥的目标位置为用户数据目录的 `secrets/session-secret.txt`。迁移前检查现有两处密钥，只选取本次有效服务使用的一份，备份后迁移；两份不一致时一次性重新登录。密钥限制为当前 Windows 用户可读，任何日志与诊断包不包含密钥正文。

### 能力包

能力包用途分为本地文案、配音、字幕识别和人物口型。每包登记版本、清单校验、运行时、依赖资源、输入格式、输出格式、测试结果和卸载影响。用户只看到用途，不需要认识底层模型名称。来源、校验或验证任何一项失败，都不能激活按钮。

## 17. 制作计划状态与数据合同

### 计划与任务状态

计划状态与单个队列任务状态分开保存。新增状态是拟实施合同，不表示当前 QueueService 已支持。

| 计划状态 | 含义 | 允许的下一步 |
| --- | --- | --- |
| draft | 正在填写需求或分镜 | 确认后进入待开始；不占用 GPU |
| ready | 分镜、素材与可用规格已确认 | 原子创建计划节点并开始；重复提交返回同一计划 |
| running | 节点依赖满足后逐项执行 | 继续、请求暂停、请求停止，或进入阻塞/预览 |
| pause_requested | 等当前段完成后暂停 | 当前任务真实结束后进入 paused |
| paused | 不再派发后续节点 | 继续或取消剩余计划 |
| cancelling | 已发出本任务定向停止 | 等引擎确认停止；不能提前显示已取消 |
| cancelled | 用户停止已完成确认 | 保留已完成资产；以新执行批次继续未完成部分 |
| blocked | 等待素材、验收、配置修复或用户决定 | 修复后重新核验依赖，再继续 |
| failed | 有不能自动恢复的执行失败 | 用户明确重试失败节点或修改方案 |
| preview_ready | 有通过技术质检的成片 | 预览、返工、保存；不等于用户内容验收通过 |
| completed | 用户已确认并保存交付版本 | 查看、复制或新建返工版本 |

节点使用 pending、waiting_input、queued、running、succeeded、failed、cancelled、invalidated。现有任务的 queued、running、paused、succeeded、cancelled、terminal_failed 继续保留，迁移时建立明确映射，不直接重写历史任务状态。

### 核心字段

| 记录 | 必须保存 | 关键约束 |
| --- | --- | --- |
| 制作计划 | project_id、plan_id、revision、状态、用户、需求快照、创建时间 | 分镜变更生成新 revision，不覆盖已确认快照 |
| 计划节点 | node_id、类型、依赖 ID、状态、输入指纹、task_id、结果资产 ID | 同一计划版本与输入指纹只创建一次实际任务 |
| 路由决定 | 镜头 ID、硬约束、候选、排除原因、所选档位、规则版本 | 必须可解释；执行时再次验证准入，不能只在首页检查 |
| 镜头版本 | version_id、输入素材、参数、模型指纹、种子、QC、用户选定标识 | 手动选定版本有保护标识，不被后续自动结果覆盖 |
| 审计事件 | 操作者、时间、对象、动作、原状态、新状态、关联执行 ID | 日志不含密码、会话令牌与完整敏感素材内容 |

所有节点依赖必须属于同一项目与计划版本，依赖图禁止环。项目复制生成新的项目、计划与资产引用身份；不能带走旧任务租约和进行中状态。

### 恢复与并发

开始操作用请求幂等键，计划创建、节点创建与任务入队在事务内完成。重复点击不增加相同渲染；用户“换一版”明确产生新的版本和种子。

重启后先检查旧任务的引擎 prompt_id 和租约：仍在执行则重新关联观察；引擎已结束且输出可校验则恢复登记；不能确认是否在执行时阻塞人工处理。不能在旧引擎任务未停止时直接重派同一任务。

成功资产同时满足文件存在、大小与校验值一致、输入指纹匹配和 QC 通过才复用。缺失或损坏的当前资产只使其下游节点失效，其他有效镜头不重做。镜头 A 的声音变化还必须使对应字幕与合成失效。

单 GPU 执行锁覆盖多个 Worker 进程，认领采用数据库互斥事务与租约；不能只先查询一次“有没有 running”。未来配音、识别和口型任务也使用同一资源门禁。

停止包含项目请求、取消标记、Worker 检测、按 prompt_id 删除排队项/中断运行项、确认引擎停止、终结任务六步。停止过程中不允许其他任务误用全局中断。当前步骤不支持中断时等待它真实退出，并明确显示“正在停止”。

## 18. 自动路由与模板执行规范

### 决策优先级

| 顺序 | 判断 | 必须执行的规则 |
| --- | --- | --- |
| 1 | 准确文字 产品事实 指定台词 角色约束 | 先确定允许的制作方式，不能被用户画质偏好覆盖 |
| 2 | 有可用真实素材 | 优先复用符合需求的素材；替换需由用户决定 |
| 3 | 输入与声音能力 | 当前文生图不能当作参考图流程；精确口型必须具备独立能力 |
| 4 | 本机技术验收 | 精确匹配配置指纹、模型、方向和时长；无记录则排除 |
| 5 | 题材与用户偏好 | 在剩余合格候选中按题材与用户选定样片偏好排序 |
| 6 | 实测记录与确定性排序 | 以有效历史失败率与耗时辅助；缺数据不编造，最终用固定模型 ID 保证结果稳定 |

不得以低失败率自动选择不符合台词、参考图或产品准确性要求的流程。质量偏好只属于用户选择，不生成没有依据的统一画质分。

路由结果须包含主推荐、最多两个可用备选、中文理由、被排除原因及需要用户补充的事项。用户指定模型不适配时显示原因，不能直接绕过门禁。

同题材偏好保存用户 ID、题材、方向、所选模型、配置指纹与选择时间。模型配置变化后偏好转为“需要重新比较”，不能变成准入依据。

无候选时保持 blocked，提供可确认的替代计划。例如“20 秒 H3”只可提出若干已验收短镜头或其他已验收模型；确认替代方案后重新生成快照。系统不得默认视用户沉默为同意。

### 模板字段与声音策略

每个模板固定 template_id、版本、适用题材、输入需求、镜头职责、必需素材、声音策略、生成方式候选、字幕要求和导出默认值。模板文字可修改，版本及执行约束需记录。

六条制作流程沿用第 5 节。产品教程约束为真实演示优先；知识讲解以准确声音时长安排画面；真人口播保留原音；AI 表演允许自由环境声；故事片冻结角色描述；广告中的产品文字作为真实图层。

30/60 秒是项目目标总时长。生成镜头仍使用已验证档位；按实际输出长度与声音时间轴裁剪并拼接。声音长度超出目标时，提示延长成片或重新录制，不能为了凑时长随意加速指定台词。

## 19. 媒体交付与质量检查规范

以下数值是本稿定义的目标交付要求，不是已有实测结论。规则与阈值必须有版本记录；变化后重新验证受影响的交付流程。

| 项目 | 目标规范 | 失败或例外处理 |
| --- | --- | --- |
| 视频 | MP4、H.264、yuv420p、24fps、像素宽高比 1 比 1 | 全量解码失败阻断；不以扩展名代替探测 |
| 输出尺寸 | 横屏 1920×1080、竖屏 1080×1920 | 默认等比补边；裁切需预览确认；不称为原生生成清晰度 |
| 音频 | AAC、48kHz、双声道；静音轨明确标识 | 导入其他格式先在本地转换，原文件保留 |
| 指定旁白 | 不截词、不擅自加速、不修改内容 | 长度冲突交给用户确认 |
| 项目目标时长 | 最终误差不超过 0.5 秒 | 不以截断台词满足容差；可申请改变目标并更新快照 |
| 单镜头时长 | 生成档位保持模型帧数网格，按实际时长记录 | 当前 QC 容差为 max 0.5 秒或 5%，不等同最终整片标准 |
| 字幕 | UTF-8 SRT；时间不倒退、不重叠越界；最多两行 | 默认烧录，也保留独立 SRT；需要调整时提示人工校时 |
| 字幕安全区 | 四边至少保留画面宽高的 5% | 这是工作台默认值，不承诺适配所有平台按钮遮挡 |

旁白响度的设计默认目标为负 16 LUFS，真峰值不高于负 1 dBTP，仅作为本地导出预设，不宣称为所有发布平台标准。该预设必须有本地测量与试听验证；未安装测量能力时不显示“响度达标”。背景声默认降低到旁白之下，并提供试听与恢复原音；数字比例不能替代听感判断。

黑帧与异常静帧检测用于告警，不直接等同损坏：故事中的夜景、停顿和真实教程定格都可能被误报。首轮以带标签的夜景、定格、正常运动和损坏样例校准，保存阈值、样例和误报记录；校准未完成时状态为“待人工检查”，不得写为自动通过。

自动质检至少输出规则 ID、规则版本、输入资产、测量值、结论和证据。技术失败阻断合成；内容类告警允许用户预览并记录确认。事实准确、人物连续性、口型观感与字幕错字仍由人检查。

| 用例 | 前置与操作 | 通过标准与证据 |

| STORAGE 01 | 用测试副本模拟文件缺失、损坏和空间不足 | 不删原素材；不复用损坏文件；显示可恢复的明确原因 |
| BEGINNER 01 | 新手按内置手册分别完成教程、知识片、创意片 | 无 Codex、无节点、无命令，能独立保存并定位成片；保留步骤与困难记录 |

### 外联观测步骤

先确定属于本次部署的 Web、Worker、ComfyUI 及子进程，记录可执行路径、PID 和父子关系。启动前开始采集 Windows 防火墙/WFP 事件与连接、DNS 证据，采集本身失败必须记“未测试”。仅执行一次 netstat 或仅看到页面可打开，不能证明没有短时外联或 DNS 请求。

依次进行冷启动、新建项目、生成、声音/字幕处理、合成、保存、重新打开和缺文件操作。检查是否存在更新检查、下载、代理及重定向外联。区分工作台进程、普通浏览器后台进程与其他系统程序；整机零流量仍以断网使用为准。

防火墙约束由维护部署阶段为专用运行时建立，以部署 ID 命名并备份原规则；保留回环通信。回退只删除本部署创建的规则，不关闭整个防火墙、不修改共享 Codex Python 或日常浏览器。规则是否实际放行回环，必须在目标 Windows 上验证。

### 十次正式档位记录

组合身份为模型 ID、模型/引擎/桥接/工作流指纹、硬件、方向、目标时长与参数档。测试从空记录开始保存十条独立运行，不能用反复读取同一个缓存输出算十次，重试也不能覆盖失败记录。

每条记录包括 run_id、seed、开始/结束时间、成功、失败类型、OOM、损坏、耗时、显存峰值、系统内存峰值、温度采样摘要、实际时长、文件 SHA256、QC 证据与人工评价。指标采集失败为缺证据，不以 0 或估计值充数。

音画同步要有适用性字段。原生音视频可记录人工是否同步及评价来源；Wan 静音或完全不涉及对口型的项目可记“不适用”及原因，不伪造同步分数。当前代码强制成功样本填写数值 `av_sync_score`，实施时必须修改合同与校验兼容这种情况；不能直接填零绕过它。

技术门槛继续为 10 次中至少 9 次成功，且全部运行无 OOM、无损坏；任何必需指标缺失则不得宣称验收完整。用户的画质偏好作为独立记录，不混成技术成功率。

记录模板只定义字段、填写说明和未测试状态，本稿不预填任何真实通过数据。第一阶段先完成至少一个常用模型方向规格与三类作品闭环；其余规格逐档验收后开放。

## 21. 项目保存备份清理与回退

### 保存和复制的区别

“保存视频”导出最终 MP4 和可选 SRT，不代表已经备份项目。“备份项目”包含原素材、选用与锁定的镜头版本、声音字幕、分镜、计划快照、模型指纹与文件清单。“复制项目”创建新的可编辑副本，复用本地只读原素材，不复制旧执行租约；需要便携副本时使用完整备份。

默认不把模型权重装入每个项目备份，但保留模型校验、版本和重新定位要求。没有匹配模型仍可查看已有成片，不能保证继续重生成。复制别人的项目时仍须执行原有访问权限校验。

### 备份与恢复步骤

用户在“我的作品”选择项目 → 点“备份项目” → 选择本地盘或移动硬盘 → 显示包含内容与所需空间 → 完成后核对清单和校验。备份失败不显示成功，备份文件与原数据放在同一块磁盘不能算防磁盘损坏备份。

系统级备份先等待执行任务进入安全边界；通过 SQLite 一致性备份导出数据库，而不是在 WAL 写入时只复制一个 db 文件。冻结本次资产清单，再复制并校验文件，最后写“备份完成”标记。副本核对完成后才释放被引用资产的清理锁。

恢复先校验备份 → 选择新目录 → 核对文件、数据库版本和可用模型 → 导入为新项目或经确认恢复指定项目 → 打开并解码成片。已完成任务只恢复为历史，不自动重跑；不覆盖正在使用的数据库。

### 清理与诊断

默认只建议清理失败任务的临时文件、过期缩略缓存和用户确认不要的旧导出副本。原素材、当前选用版本、用户锁定版本、有效备份引用和模型权重均不在自动清理范围。

清理先显示清单和预计释放量，经用户确认后移入本地回收区，保留 7 天；永久删除是单独动作。当前活动任务或恢复中的项目被引用文件不能清理。日志默认保留 30 天，重要验收证据随项目保留，不按普通日志自动清除。

诊断包默认仅含版本、错误码、脱敏日志和路径摘要，不含密钥、原素材、完整文案和录音。导出前可预览内容，保存到本地，不自动上传。

### 离线更新与回退

更新前保存一致性备份，校验可信离线包，在新版本目录准备，不覆盖当前运行目录。先用数据副本迁移与测试，再在任务安全边界切换版本；保留旧程序与匹配的数据库备份。

回退必须成对恢复旧应用和迁移前数据库，不能让旧程序直接使用不兼容的新表结构。回退后对新增资产进行隔离登记，不静默删除。配置指纹改变时只重验受影响档位，旧通过记录保留为历史。

## 22. 界面文案与操作边界

首页空状态显示“先做一条小视频”，提供教程、知识讲解、故事广告三个可修改例子；个人默认导航仍只有开始制作、我的作品、素材库。状态文字必须说明当前真实阶段，不显示后台枚举英文。

分镜列表只显示序号、画面描述、台词/声音、来源、时长和需补内容。“为什么这样安排”展开解释路由。高级参数默认只读；启用专家编辑会创建新参数版本，任何未验收参数导致生产门禁重新检查，不直接修改生产预设。

“确认并开始制作”只对具备权限的当前用户生效。个人模式把确认、审批与快照建立合并为一个事务并留审计；团队模式保留原管理员审批权限。离线不等于免登录，不建立全员通用的默认密码。

| 界面情形 | 中文提示 | 主动作 |
| --- | --- | --- |
| 文件齐但规格未验收 | 模型文件已准备，这一制作规格还未验证 | 准备这一规格 |
| 精确配音包未接通 | 还不能自动配音，可以先用自己的声音 | 录音或导入声音 |
| 引擎首次加载 | 正在准备本机模型，完成后继续制作 | 查看当前阶段 |
| 无法估计剩余时间 | 正在制作第几段，剩余时间暂不能准确估计 | 暂停后续制作 |
| 关闭界面 | 关闭窗口后任务仍会继续 | 继续后台制作；另选完成当前段后暂停 |
| 停止未确认 | 正在等待本次生成停止，已完成片段会保留 | 查看状态，不显示虚假停止成功 |
| 成片技术检查通过 | 已可预览，请检查内容与声音 | 预览并保存 |

关闭窗口不自动等于暂停；用户选择的行为在设置中明确可见。首次准备向导支持保存进度、返回和分批验收，重新打开不要求从头开始。

导出文件名由项目名、版本和时间生成，替换 Windows 不允许的字符；内部使用 ID 目录减少路径长度问题。中文和空格照常支持。路径不可写或过长时提示选择其他位置，不改成系统临时目录后冒充已经保存。

## 23. 阶段退出标准与需求追溯

本节定义交付边界，不代替设计审阅后的逐任务实施计划。具体开发任务仍需包含文件范围、接口、测试、迁移和回退步骤。

| 阶段 | 退出必须具备 | 不能作为通过的替代 |
| --- | --- | --- |
| 一 独立离线闭环 | 专用运行环境、桌面入口、六类模板框架、受准入约束的路由、整片编排、录音/导入、字幕编辑/导入、合成导出；三类新手作品和离线/恢复用例通过 | 只展示页面、只跑小样、只在 Codex 内执行脚本 |
| 二 减少手工准备 | 每个新增文案/配音/转写包有清单、门禁、实际输出与离线证据；不可用状态清楚 | 文件已下载但适配器未接通；视频编码器冒充文案模型 |
| 三 角色与画面控制 | 图片与首尾帧输入全链路通过，角色参考、口型、长档位和超分分别验收 | 同一种子、一次样片或导出 1080p 就认定身份稳定和原生高清 |

每阶段交付版本都重新运行适当的完整回归测试和真实样片，不沿用旧 104 项测试作为新功能的证明。未完成项保留明确状态，不能仅因为处于某阶段就自动变为通过。
