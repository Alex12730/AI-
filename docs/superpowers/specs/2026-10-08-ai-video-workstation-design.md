# AI 视频自动化工作站 MVP 设计规格

## 目标与边界

本规格把用户确认的方案固化为实现依据：在单张 RTX A6000 48GB 工作站上建设纯本地视频生产平台，覆盖脚本、分镜审批、镜头队列、本地模型执行、合成质检、人工验收和归档。MVP 不下载大模型权重、不伪造硬件基准、不接入云端生成服务；它交付可运行的平台、持久化任务系统、本地安全适配器、模拟执行器和真实模型准入工具。

## 核心流程

1. 成员创建项目并录入脚本。
2. 系统生成可编辑的分镜草案；MVP 使用确定性本地拆解器，后续可替换为本地 Qwen。
3. 成员提交分镜，管理员审批。
4. 已审批镜头按模型路由入队；重型 GPU 任务单并发执行。
5. Worker 使用心跳与租约认领任务，基础设施错误最多自动重试一次。
6. 生成资产进入 FFmpeg/ffprobe 质检；画质与真实性由管理员人工验收。
7. 通过验收的项目保存可追溯清单，并允许归档到配置的机械盘目录。

## 角色与权限

- `member`：访问自己创建或获授权的项目；编辑草稿；提交审批；对已批准镜头发起生成；取消自己项目中尚未运行的任务。
- `admin`：拥有成员能力，并可审批、调整优先级、重试/取消任务、启停模型档位、录入基准结果、管理用户和验收项目。
- 首个管理员必须通过 CLI 显式创建并输入密码；系统不得内置默认密码。

## 数据模型

`User`、`Project`、`Storyboard`、`Shot`、`Task`、`Asset`、`Review`、`ModelProfile`、`AuditLog`。所有关键变更产生审计记录。任务至少保存状态、优先级、尝试次数、租约、输入参数、模型版本、量化版本、随机种子、输出路径和失败分类。

## 队列规则

- 状态：`draft`、`pending_approval`、`queued`、`running`、`succeeded`、`retryable_failed`、`terminal_failed`、`cancelled`。
- 优先级：P0 仅管理员；P1 营销；P2 系列；同级 FIFO。每等待 60 分钟提升一级，最高到 P0。
- 单 Worker 原子认领一个重型任务；租约过期任务在启动恢复时重新排队。
- `infrastructure` 错误可自动重试一次；`quality` 错误不得自动重试。
- OOM 不降级参数，返回可选的已验证低显存预设。

## 模型路由

- 文本拆解：本地 Qwen，人工确认。
- 产品 UI：真实录屏/截图动效，禁止生成模型伪造。
- B-roll/空镜/运动：Wan 2.2。
- 人物表演、电影感、首尾帧与环境声：MiniMax H3 FL2VA。
- 长连续镜头备选：LTX-2.3，默认禁用，基准通过后启用。
- 精确口播：CosyVoice 3 + MuseTalk 1.5。
- 合成：FFmpeg；超分/补帧：Video2X，默认关闭。

## MiniMax H3 准入

H3 Profile 默认启用本地适配器但不开放未验证时长。仅 FL2VA；768p、24FPS、32kHz 立体声能力作为模型元数据展示，不作为本机性能结论。5/10/15 秒与 16:9/9:16 各需连续 10 次测试；无 OOM、无损坏文件且成功率至少 90% 才开放该组合。每次测试保存耗时、显存峰值、内存、温度、音画同步评分和失败原因。

H3 本地命令以 JSON 参数数组配置并通过 `shell=False` 执行。MVP 不接入 Context-IR、Regenerate-2K 或任何云端 API。许可证版本、NOTICE、显示名称、AI 生成标识、地域与 2000 万美元年收入阈值必须可见。

## 安全与存储

- Argon2 密码哈希；会话 Cookie 为 HttpOnly、SameSite=Lax，生产环境要求 Secure。
- 所有外部命令使用参数数组；提示词不参与 shell 拼接。
- 资产路径由系统以 UUID 生成并校验位于配置根目录内。
- 新任务入队前检查：剩余空间至少 100GB，且至少为预计临时空间的 2 倍。
- 应用不实现外网客户端；本地模型适配只允许配置的可执行文件和 loopback 端点。
- 日志不记录密码、Cookie、完整敏感素材内容。

## 验收分层

软件验收可在没有模型权重时完成：认证、权限、分镜审批、持久化队列、租约恢复、安全命令、模型档位、模拟生成、质检接口和审计追溯。硬件/模型验收必须在 A6000 工作站安装权重后执行，不能由单元测试替代；未通过时 UI 持续显示“未验证”。
