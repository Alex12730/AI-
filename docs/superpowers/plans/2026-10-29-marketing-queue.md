# 作品级营销插队实施计划

目标：确认制作时允许把作品标为“营销优先”，在当前镜头完成后让营销作品先做；同级按提交顺序，结束或失败后普通作品自动继续。只使用现有单 GPU Worker 和持久化队列。

1. 在确认页增加营销优先选项，冻结到 CreationPlan 快照；文案生成和定稿文案共用该确认入口。
2. 调度器每次先推进最早提交且仍在运行的营销作品。其他营销作品等待；普通作品记录让行原因，不继续派发后续镜头。已经运行的镜头不取消，已排队的普通任务保持但优先级低于营销任务。
3. 营销作品完成、失败、阻塞或人工暂停后，解除让行并恢复普通作品。用户主动暂停不被自动解除。
4. 测试当前镜头边界、两件营销作品顺序、失败恢复、重复调度无重复任务，以及页面标识。

边界：此阶段不处理独立高级项目任务的营销优先级；不提供强行中断正在采样的模型任务；连续不断提交营销任务时的公平上限留待单独配置。
