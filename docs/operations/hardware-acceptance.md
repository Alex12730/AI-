# 工作站硬件验收

## 到货与固件

- 拍照记录整机、GPU、主板、SSD、机械盘序列号与保修状态。
- BIOS 加载稳定默认值；确认 Intel 微码/ME 与主板厂商稳定版，不以极限超频作为交付状态。
- 确认内存双通道与容量；DDR5-6000 属于超频档，稳定性优先。
- 记录 RTX A6000 驱动版本、空闲功耗/温度、风扇和显存总量。

## 48 小时稳定性

- CPU、内存、NVMe、GPU 分项压力测试，再执行混合负载。
- 记录温度、降频、WHEA、驱动重置、ECC/显存错误、系统重启与磁盘 SMART。
- 温度按机箱、环境温度和厂商规格判断，不使用不现实的统一“低于 65°C”门槛。
- 任何 WHEA、文件损坏、驱动重置或不可解释重启都算失败，先处理再重新计时。

## 签字记录

保存日期、操作者、工具版本、原始日志、结论和异常处置；不要只留一张“通过”截图。
