# MVP 验收清单

## 软件自动验证

- [ ] `pytest -q` 全部通过。
- [ ] `compileall` 无语法错误。
- [ ] Alembic 在空数据库升级成功，Web/Worker 使用同一数据库。
- [ ] 封锁外部 socket 后，Demo 项目可完成创建、审批、入队和 Worker 收尾。
- [ ] 重启时过期租约回到队列，任务不重复执行。
- [ ] 普通成员无法访问他人项目、审批分镜、使用 P0 或打开模型管理页。
- [ ] 低于 100GB 或不足预计临时空间两倍时拒绝入队。

## 模型准入

- [ ] Qwen、Wan 2.2、H3、LTX、CosyVoice、MuseTalk 分别记录版本、量化、许可与命令。
- [ ] H3 5 秒 16:9/9:16 各 10 次通过。
- [ ] H3 10 秒 16:9/9:16 各 10 次通过。
- [ ] H3 15 秒按实测决定；未通过时界面不可选。
- [ ] 模型切换后显存释放，连续 OOM 不触发隐式降级。

## 成片与恢复

- [ ] 完成一条 30–60 秒产品营销片；产品界面全部来自真实录屏/截图。
- [ ] 完成一条系列视频/短剧样片。
- [ ] 输出为 1080p、H.264/AAC，并覆盖 16:9 与 9:16。
- [ ] 自动识别损坏文件、缺失音轨和时长偏差；黑帧/异常静帧阈值以真实素材标定。
- [ ] 管理员人工检查人物一致性、肢体、口型、文字和产品真实性。
- [ ] 断电/服务重启演练后任务不丢失、不重复。
- [ ] 72 小时混合任务运行无 Web 被模型拖垮、无磁盘打满、无素材外传。
- [ ] 每条成片能回溯分镜、模型、量化、参数、随机种子、素材、审批与 NOTICE。

验收人、日期、工作站序列号、驱动版本、原始日志路径和未通过项必须一并保存。未勾选项不能用“计划完成”替代实测结果。
