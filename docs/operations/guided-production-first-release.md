# 简易制作：第一批代码操作说明

日期：2026-10-22。本说明只描述本批已经实现的功能。完整离线部署、声音处理和高级返工按设计分阶段继续完成。

## 从哪里进入

打开本机 `http://127.0.0.1:8000/create`。尚未创建账号时，先在 `/setup` 设置自己的管理员账号；系统没有默认密码。登录后默认进入“开始制作”。日常制作无需进入 ComfyUI。

当前后台仍使用既有 `.venv`，其基础 Python 尚依赖开发工具缓存，不能认定已完成独立部署。已下载权重继续复用，不需要重复下载。关闭浏览器标签页不停止后台；退出 Worker 或关机会中断当前镜头。

## 实际操作

1. 在“开始制作”填作品名称，选择类型，填写内容或现成文案。
2. 设置整片时长和方向。目前每镜头固定 5 秒，整片支持 5–180 秒的五秒倍数。按句号、问号、换行等拆句；内容多于镜头数量时会要求精简或增加时长，不会静默丢掉内容。
3. 点“下一步：安排分镜”。这里只建草稿，不消耗生成算力。
4. 逐段检查。展开“修改这段内容”可改标题、画面描述。模板补充的镜头尤其需要检查；模板模式没有自由理解内容的文案模型。
5. 对软件操作、产品准确外观和真人口播，展开“导入 / 更换真实视频”，选择约 5 秒的 MP4、MOV 或 WebM，点“导入并使用”。暂不自动裁剪，请先把视频剪为需要的短段。
6. 导入文件会通过质检并自动绑定。展开素材选择可切换该镜头历史视频；不自动使用最新上传替换已确认的素材。
7. 自动生成镜头会显示推荐模型及理由。如果显示“需要准备”，先在“帮助与设置 → 模型与准入”检查正式验证状态，或换成真实视频。当前三个模型虽已接入，历史小样不等于五秒正式档位验收。
8. 所有段落准备好后，点“确认并开始制作”。这会以本人身份批准这次个人分镜，冻结模型指纹、种子、内容及素材 ID。仅创建者可确认；原团队项目仍走审批流程。
9. 在制作页查看每段状态，点“刷新进度”更新。后台按顺序生成并自动合成，无须逐段点运行。一个镜头失败时停止后续派发，不静默换模型或降画质。
10. 点“暂停后续制作”，当前已经入队的段落结束后暂停；点“继续制作”恢复。本批没有运行中即时停止按钮。
11. 成功后显示成片播放器与“保存视频”。默认使用本地 FFmpeg 输出横屏 1920×1080 或竖屏 1080×1920、24fps、H.264/AAC。导出分辨率不等于模型原生细节。

“我的作品”保留个人向导项目。旧项目在“帮助与设置 → 制作工作台”中继续访问；制作页底部也可进入详细项目。

## 六种类型怎么选

| 类型 | 当前安排 | 声音与限制 |
| --- | --- | --- |
| 产品 / 软件教程 | 所有段落使用真实视频 | 保留视频声音；不能自动生成真实按钮和准确界面 |
| 知识讲解 | 讲稿分段，环境镜头或自行导入视频 | 没有自动朗读；想要讲解声请导入自己已录好的视频 |
| 真人口播 | 导入本人拍摄的短段，再合成 | 不自动纠正口误或识别字幕 |
| AI 人物表演 | 优先已验证 H3，LTX 为候选 | 可有原生声音，不保证逐字台词与精确口型 |
| 故事短片 | 按场景拆段；环境画面优先 Wan | 不保证跨镜头角色一致；人物表演段使用音视频候选 |
| 创意广告 | 真实产品镜头与生成环境交替 | 包装、商标、价格须在真实素材中准备 |

只有已启用、已经配置且当前五秒/画幅档位通过准入的真实视频模型才能自动入队。Demo 不参与自动路由。H3 当前不接受负面提示词，不会为运行任务而悄悄删除此约束。

## 本批验证及后续事项

本批完整测试 121 项通过，包含真实 FFmpeg 十秒成片；浏览器完成 1280 宽屏及 390 窄屏检查。独立代码审查发现的并发覆盖问题已通过两会话与损坏快照测试修复，队列原子认领增加全局运行状态复查。

这些证据尚不代表三个模型的正式画质、全电脑零流量或断电恢复已经验收。后续包括：项目专用 Python 和桌面入口、首次准备/正式基准向导、图片和独立音频/字幕流程、定向停止、旧 Comfy 任务恢复、版本锁定/局部返工、备份恢复、整个项目的严格时长控制及真实断网验收。当前尚不能把完整设计标为交付完成。
