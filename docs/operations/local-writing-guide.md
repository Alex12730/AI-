# 本地文案工作室操作说明

本阶段已接通一句话生成中文文案、分镜草稿、手工编辑、定向改写、历史版本和确认发布。每天使用浏览器即可操作，无需在 Codex 发指令。

## 第一次使用

1. 启动本机工作台，打开 `http://127.0.0.1:8000/create`，用原有账号登录。
2. 在“你想做一个什么视频？”输入想法，例如“小女孩在森林寻找萤火虫，最后把它们放回树林”。
3. 选择视频类型、横竖屏和目标时长。建议先用 10–30 秒；第一版仍以每段 5 秒安排镜头。类型旁的说明用于解释当前流程，并不是第二个选择入口。
4. 点击“生成文案”。可离开页面，到“我的作品”重新打开；任务和结果均存本机。前面有任务时会排队。
5. 候选出现后，先阅读，再点“使用这版，继续修改”。生成结果不会自动替换编辑稿。
6. 修改标题、概要、完整文案；展开“检查和修改分镜建议”修改画面描述和逐段旁白。修改正文不会自动同步分镜，需同时调整，或保存后要求模型重写分镜。
7. 点击“保存我的修改”，得到新的历史版本。未保存时切换候选、改写或继续，会先提醒保存。
8. 需要其他写法时，可选“另写一版”“更简短”“更口语”“改结尾”，或填写具体要求。新版本在候选区比较，原稿保留。
9. 满意后点击“确认文案，查看分镜”。这里只创建本次分镜计划，不会立即启动视频模型。核对镜头和素材后再开始制作。

已有完整文案可展开首页“我已有完整文案”，继续使用原有模板流程。仅想记录灵感可点“先保存想法”，不启动模型。

## 查看运行状态与返回页面

文案页顶部显示“排队”“正在本机生成”“文案已就绪”或失败原因，每 5 秒自动更新。运行时显示已运行秒数和最近心跳时间；心跳过期会提示状态待确认，不把失联当作正常运行。可以点击“检查运行状态”立即检查，或“查看任务队列”查看任务记录。状态请求失败时保留上次结果并明确提醒，不清空编辑区。

已有文案任务时，生成与改写按钮暂时禁用；同作品重复提交相同请求会复用正在等待或运行的任务，不再新增任务。仍可编辑和保存当前稿件。

各页面顶部都有“返回上一页”和“返回开始制作”。从本站页面跳转而来时，前者回到上一个页面；直接打开的新页面没有本站历史时，回到开始制作。文案有未保存修改时，离开页面会由浏览器提醒。

## 保存、回退和事实核对

“我的作品”按作品汇总文案和已确认的制作计划。历史版本可以重新选择；确认新版本会建立新计划，不改动旧计划和已制作素材。多标签页同时编辑发生冲突时，页面保留本次输入，请先比较最新版本。

分镜页的“AI 生成 · 等待模型验证”表示该段不强制上传素材，只需对应的视频模型档位通过验证；“需要真实素材”才表示需要真实录屏、产品实拍或自己的口播。故事、知识与 AI 表演不会仅因写作模型误填产品界面标签而强制上传。已经开始制作的冻结版本不会自动改动。

本地模型会写错，也可能虚构产品按钮和知识。生成内容是待审核的草稿；产品界面、价格、标识使用真实素材，知识说明应以你提供并核实的资料为准。时长是镜头安排目标，不代表已验证的配音时长。

## 安装与维护（维护人员）

本机安装根目录为 `E:\Workspace\AI视频自动化工作流`。权重约 5.03 GB，存放在 `models/local-writer`；便携 CPU 引擎在 `runtime/local-writer/b11804`；根目录的 `local-writer-deployment.json` 保存相对路径和 SHA-256，许可证随包保留。不要手动替换其中的 EXE、DLL 或 GGUF。

以下命令仅用于明确准备/验证/登记模型；日常打开网页不下载、不检查更新、不转云端：

```powershell
# 在仓库根目录执行；准备阶段需要网络
.venv/Scripts/python.exe scripts/prepare_local_writer.py --root ../..
# 实际推理验证，约需数分钟；不会修改作品或启用视频档位
.venv/Scripts/python.exe scripts/verify_local_writer.py --manifest ../../local-writer-deployment.json --output-dir data/writing-verification/new-run --seconds 30
# 备份工作站数据库后，显式登记验证结果
.venv/Scripts/python.exe scripts/register_local_writer.py --manifest ../../local-writer-deployment.json --report data/writing-verification/new-run/results.json --data-dir data
```

安装锁定 `config/writer-source-lock.json` 中的官方来源与哈希。部署清单参考 `config/writer-deployment.schema.json`，实际运行还会验证包内路径、文件大小、哈希、GGUF 标识和 DLL 完整性。配置变化后旧的写作准备指纹失效，需重新验证登记。

每次任务通过既有 Worker 串行队列启动专有引擎，固定 `127.0.0.1:8091`、CPU、上下文 16384。模型参数使用本地绝对路径和 `--offline`，请求禁用代理和重定向，只调用回环接口；临时访问密钥不落盘。不会连接未知端口服务。端口被占用时任务明确失败；请核查对应程序，不要全杀 Python 进程。

模型缺失时按钮显示未准备，已保存稿件不受影响。失败信息在文案页，任务引擎日志在数据目录 `writing-jobs/<任务ID>/engine.log`。服务崩溃恢复只清理任务记录、PID、创建时间、EXE 路径全部匹配的进程；无法确认时保留进程并提示错误。

知识样稿错误地描述彩虹在太阳与观察者之间，不能直接发布。以上结果仅证明本地生成和结构合同，不是事实准确性、最终画质或视频正式档位准入证明。原始样稿和报告在本机忽略目录 `data/writing-verification/20261022-fixed`。样本耗时不作为速度保证。首次失败发现固定版本 server 文档的 JSON schema 示例与实现不同，现按固定版本源码修正并有回归测试。

内存观测：首次结构失败的推理进程峰值工作集约 10.57 GB；成功用例未单独采集峰值，不能把该值当作成功用例的资源上限。另用隔离测试数据完成了网页提交十秒故事 → Worker → 实际模型 → 候选展示，任务成功。最终自动化测试 160 项通过，49 条依赖弃用提示；独立审查的三个问题均已修复并复审。

不修改全机网卡或代理的前提下，本批验证了本地路径、回环调用、代理/重定向阻断与缺文件不自动下载；尚未做物理断网后的全链验收。完整的独立 Python、声音和角色流程完成后，应关闭 Codex 并断网逐项验收。
