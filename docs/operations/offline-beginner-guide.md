# 全离线视频工作台：新手操作手册

日期：2026-10-22。请先区分：第一部分是当前已实现界面的用法；第二部分起是本次设计的目标用法，需完成开发和验收后才能照着点击。不要把设计中的按钮当作已经安装。

详细设计见 [个人全离线视频工作台设计补充](../superpowers/specs/2026-10-22-personal-offline-video-workstation-design.md)。

## 一、当前版本你已经能做什么

三个模型已下载并接通，小样生成曾验证成功；但当前模型数据库没有正式档位准入记录。现在不是选个模型就能在普通项目中生产，不能用 Demo 绕过验收。下一次开发需要把一次性准备/验收做成可点击向导。

当前启动不用打开 Codex：

1. 在文件管理器打开 `E:\Workspace\AI视频自动化工作流`。
2. 右键 `启动视频自动化工作站.ps1`，选择“使用 PowerShell 运行”。如果系统隐藏该选项，不要求新手修改安全设置，改由安装阶段建立正确的桌面快捷方式。
3. 等待服务启动，在浏览器地址栏输入 `http://127.0.0.1:8000`。这是本机程序，不是互联网网站。
4. 第一次使用，在 `/setup` 设置自己的管理员账户；已有账户则登录。不需要 GitHub 登录。
5. 保留原始视频、图片、音频的本地副本。不要删除 `models`、`runtime`、`source/AI-/data`。

现有网页的制作顺序：

1. 首页点“新建项目”，填写“项目名称”“原始脚本”，点“生成分镜草案”。
2. 在项目页展开“编辑镜头内容与参数”，设置每段内容、时长和画幅；目前每句拆一镜头，并非智能导演。
3. 点“提交审批”，再用管理员身份点“批准分镜”。当前个人使用仍需这两个步骤。
4. 真实录屏镜头展开“上传真实录屏”，选择本地视频，点“导入素材”。
5. 生成镜头只有通过对应时长/画幅验收的模型才会出现，选择后点“加入队列”。看到“暂无已验证模型”时，缺的是正式验收，不是让你重新下载模型。
6. 所有镜头有合格素材后，在“本地合成成片”选择各镜头版本，必要时上传本地 UTF-8 SRT，点“加入本地合成队列”。
7. 在“项目成片”预览并下载。

这套流程目前还不够适合新手，下面是计划改造成的用法。

## 二、改造后第一次使用：只做一次准备

1. 双击桌面“视频工作台”，不打开 Codex，不操作模型节点。
2. 选择项目保存目录。模型目录直接复用已有文件，不重新复制。
3. 工作台检查显卡、磁盘、专用 Python、视频工具和模型文件，列出缺项。
4. 选择要先验证的规格。建议从“横屏、5 秒单镜头”或“竖屏、5 秒单镜头”开始；整片仍可拼成 30/60 秒。
5. 点“开始准备和验证”，等待真实试片/正式档位测试。每个正式组合测十次，可能较久；无需每个新项目重测。
6. 试听样片，并在界面确认音画观感。系统保存真实记录，不代填满分。
7. 选择所需能力：基础制作必备；自动写稿、自动配音、识别字幕、人物对口型只有本地能力包已安装并验证后才启用。
8. 断开 Wi-Fi/网线、关闭 Codex，重新打开工作台，做一条小片并保存。通过后显示“离线验收通过”。

如果任何一步提示缺文件，就从已准备好的本地离线包或 U 盘导入。日常制作过程不会联网补齐。

## 三、以后每次做视频：统一四步

### 1. 说明要做什么

点“开始制作”，输入需求，例如：

> 做一个 30 秒竖屏视频，介绍三种整理桌面的方法。语气自然。用我自己的录音，加简短中文字幕。没有真实人物说话镜头。

选择总时长与横竖屏，加入素材。不知道模型怎么选就保持“自动安排”。

### 2. 看一遍镜头安排

检查每段要展示什么、说什么。缺素材的段落会标出“需要你加入录屏/图片/声音”，先补齐或改方案。

如果只想让系统接着做，点“确认并开始制作”。不需要自己把每段加入队列，也不需要在个人模式中提交给自己再审批。

### 3. 等待制作，可先看已完成片段

能看到当前制作到第几段。当前模型第一次加载可能较慢；没有可靠剩余时间时，界面会显示真实阶段。

关掉页面后任务可继续；要暂停就点“暂停后续制作”，让当前段完成后停下。点“停止当前生成”会丢弃当前未完成片段，已完成片段不丢。

### 4. 预览并保存

检查错字、配音、音量、画面内容和产品事实。满意点“保存视频”，再点“打开文件夹”。

某一段不满意，点该段“换一版画面”或“修改描述”，不用重做整个项目。满意版本可以随时选回来。

## 四、完全不懂模型时，记住这张表就够了

| 你想要什么 | 系统优先安排 | 你需要知道的限制 |
| --- | --- | --- |
| 软件操作、准确按钮文字、产品真实样子 | 你的录屏/图片 | 生成模型不应该替你造假的操作画面 |
| 风景、空镜、运动画面 | Wan 2.2 候选 | 当前 Wan 输出的音轨是后补静音，不会自动有讲解 |
| 带场景声音的人物表演/短片 | MiniMax H3 候选 | 原生对白不保证逐字照稿 |
| 另一种音视频表达或已验证较长镜头 | LTX-2.3 候选 | 不意味着它在所有题材上最好；时长以本机已验证档位为准 |
| 一字不差的讲解 | 自己录、导入音频，或本地配音包 | 不让视频模型自由编对白 |
| 人脸逐字说话、口型同步 | 真人拍摄，或独立口型流程 | 不是这三个视频模型一装好就自动具备 |

这些是初始自动安排规则；你满意哪种样片，系统可以记录偏好。最终仍只选已通过本机验收的模型。

## 五、三个从头到尾的制作例子

### 例子 A：30 秒软件教程

1. 准备一段真实屏幕录制和准确讲解文案。可以自己读成录音。
2. 点“开始制作”，选择“产品与教程”，横屏，30 秒。
3. 写：“讲清楚怎样导出报表。所有按钮名称和点击顺序必须与我上传的录屏一致。”
4. 加入录屏和录音；如果没有声音，先选“暂不加配音”，不要误选不存在的自动声音能力。
5. 系统安排“开头说明→真实操作→结果展示→结尾提示”。确认它没有把操作画面安排成 AI 生成。
6. 选择是否加一段生成氛围镜头；不用也能完成教程。
7. 确认制作，预览字幕和鼠标操作是否对应，保存横屏成片。

### 例子 B：60 秒知识讲解

1. 准备已经核对过的讲稿、自己的录音和可用图片。
2. 点“开始制作”，选择“知识与口播”，竖屏，60 秒。
3. 写：“按三个要点讲解，使用画外音，不需要说话的人脸。重点词用字幕。”
4. 选择导入录音。已准备自动字幕包时再启用“识别字幕”；否则导入 SRT 或在字幕编辑中校时。
5. 系统按实际声音时长安排画面，空镜可自动推荐 Wan，图片和文字由本地合成处理。
6. 检查每段图画是否表达了正确知识点，确认制作，试听并改错别字，再保存。

### 例子 C：30 秒故事/创意广告

1. 先写清楚发生什么、画面风格和结尾，不要求第一次就连续拍摄 30 秒。
2. 点“开始制作”，选择“故事与创意”，按用途选横/竖屏。
3. 写：“雨后城市，一位穿黄色雨衣的人走进暖色咖啡店。主要靠画面和环境声表达，没有指定对白。”
4. 系统拆成数个短镜头；需要环境声时推荐 H3 或 LTX，纯街景可推荐 Wan。
5. 如果一定要同一张脸，启用已准备的角色参考流程；未准备时改成不露脸/背影镜头，或补录真实人物。不能把随机种子当成保脸开关。
6. 做广告时加入真实产品照片与商标，要求产品本体保持真实，文字叠加后期完成。
7. 确认分镜，自动生成并合成。检查人物连续性、声音和产品外观，重做不满意的单段，保存。

## 六、发生问题时

| 看到什么 | 你该怎么做 |
| --- | --- |
| “这一规格未验证” | 去设置准备该规格，或确认采用已有的短镜头组合；不用反复重新下载 |
| “缺少本地配音/字幕能力” | 录音、导入本地文件，或在准备页面导入离线包 |
| “显存不足” | 保留已完成结果，确认拆短或改用已验收方案；不要同时手开三个模型 |
| “磁盘空间不足” | 用清理预览删除确认不要的失败临时结果；保留原素材和满意版本 |
| “模型文件找不到” | 在设置中重新定位已有目录；不会自动从互联网下载 |
| “等待引擎空闲” | 先结束自己在维护界面开启的任务；不要求新手去杀系统进程 |
| 画面不满意但程序显示通过 | 技术质检只说明文件可用；用“只改这一段”返工 |

## 七、需要养成的三个习惯

1. 长视频拆成短镜头做，不要让一个模型一次承担整部片子。
2. 指定内容用真实素材或准确配音；生成模型负责合适的创意画面。
3. 在工作台里预览满意再导出，并备份项目；不要只留下最终 MP4 而删除全部源素材。
