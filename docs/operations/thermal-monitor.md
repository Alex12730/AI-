# 本机温度监测与启动

当前统一启动入口位于工作区根目录的 `启动视频自动化工作站.cmd`。双击后依次启动 ComfyUI、温度监测、网页服务和 Worker，浏览器打开 `http://127.0.0.1:8000/create`。再次启动会复用已有进程。代码运行时，`VIDEO_WORKSTATION_THERMAL_MONITOR=1` 才启用派发门禁；统一启动脚本会设置此值。

监测进程每五秒使用 `nvidia-smi` 读取 GPU 核心温度。状态文件在数据目录 `thermal-status.json`，日志在 `data/service-logs/temperature.stderr.log`。工作台所有页面顶部显示最新温度；系统页显示当日最高值和最近读数。文件丢失、损坏或读数超过十五秒未更新时，新的重型生成和放大任务暂停认领，文案编辑与已完成作品仍可使用。

本机初始阈值：80℃ 连续三十秒为提醒；85℃ 连续三十秒暂停新重型任务；90℃ 连续十秒或单次 93℃ 为紧急高温。已经运行的镜头不会被本版本自动停止。遇到紧急提示时请人工检查当前任务和散热；不能把页面提示理解为已成功取消引擎任务。温度低于 75℃ 持续两分钟且监测有效后，在运行状态页点击“温度恢复后继续制作”。已运行任务必须结束后才能继续派发。

关闭网页不停止监测进程；重启 Windows 后重新双击统一启动入口。不要为了清除告警删除状态文件：删除会被判为监测失联并继续暂停新重型任务。监测进程意外退出时先查看上述日志，再运行统一启动入口。当前没有 Windows 托盘通知，也没有可验证的定向取消能力；这两项需后续验收，页面明确提示当前任务需人工处理。

升级代码后，启动脚本核对网页、Worker 与温度进程的运行版本。它只在数据库中没有运行任务、并确认 Worker 进程属于当前数据目录时替换旧 Worker；无法确认归属时停止自动切换并提示排查，避免误停其他任务。部署新代码时同步更新 `config.py` 中的 `RUNTIME_VERSION` 与启动脚本检查值，再通过 `/health`、`worker-runtime.json` 和 `thermal-status.json` 核对三个版本一致。
